# 打擊手感規格（T8）

資料在 `hit-fx-spec.js`，格式已經跟工程師對過：`window.HIT_FX_SPEC = { <王的 kind>: { colors, size, count, speed, hitStopMs, shakePx, shakeMs }, default: {...} }`。
這個檔只有資料。火花、碎片、停格和震動都由引擎自己畫。示意圖在 [`hitfx_crackwall_design.png`](hitfx_crackwall_design.png)（A 區）。

## 王的代碼
DEVELOPMENT.md 裡沒有列王的代碼，所以直接用引擎現在就在用的 kind 字串（`world-engine.js` 的 `BATBOSS`、`world.js` 的 `o.kind`）：
`worm` 沙蟲王、`tree` 老樹精、`frog` 泥巴蛙王、`mole` 鼴鼠王、`golem` 熔岩巨人、`crab` 巨蟹王、`knight` 盔甲騎士王、`bird` 風暴鳥、`phantom` 鏡影王、`spark` 電火花王、`guard` 鐘塔守衛、`glitch` 故障機器人、`core` 故障核心。
其他東西（生物、未知的 kind）一律用 `default`。

## 欄位
| 欄位 | 意思 |
|---|---|
| `colors` | 4 個 E32 色（沒有白色 #ffffff，也沒有王招式預告用的紅色 #e43b44） |
| `size` | 碎片大小 `[寬,高]` px，每顆隨機挑一個 |
| `count` | 碎片顆數，**依打擊種類分開** `{bat, bomb, ko, fire}` |
| `speed` | 初速 `[最小,最大]` px/秒（16px = 1 格） |
| `hitStopMs` | 停格毫秒，**依打擊種類分開** `{bat, bomb, ko, fire}` |
| `shakePx` | 震動幅度，**依打擊種類分開** `{bat, bomb, ko, fire}`，上限 3 |
| `shakeMs` | 震動衰減時間（全部都是 200） |

## 火花（不用白色、不閃全畫面）
- **球棒**：核心 `#ead4aa`、外圈 `#feae34`、描邊 `#181425`。
  ①「+」字，半徑 2，0.03 秒 → ② 四條斜線 3→5px，加一道朝小光的弧，0.04 秒 → ③ 剩 3 個小點，0.05 秒。
- **炸彈**：核心 `#feae34`、圈 `#f77622`、外緣 `#be4a2f`、煙 `#8b9bb4`／`#5a6988`。
  ① 半徑 3 的實心爆點（外面包墨色），0.04 秒 → ② 半徑 6 的空心圈加四團煙，0.06 秒 → ③ 只剩半透明的煙，0.08 秒。
- 每一格只畫一次，不重複閃。最亮的顏色是沙色和琥珀色，都比小光的眼睛暗。

## 震動（建議改掉現在的）
- 現在 `world.js` 第 610 行：`shake` 是格數，每一格畫面在 ±2px 之間來回跳（大約 60Hz 抖動）。`bossdown` 是 4 格，沒有衰減。
- 建議：每 1/30 秒才換一次位置，幅度 × (1 − t/shakeMs)²，第一下往打擊方向，正負交替。`shakePx` 上限 3（遊戲像素，畫的時候再 ×SC）。

## 接到引擎（world.js 的 `HITFX`）
`world.js` 的 `HITFX` 是「每隻王 → 每種打擊 → 一個數字」（例如 `tree:{fire:{hitStopMs:90}}`）。這份規格是「每隻王 → 一個欄位 → 每種打擊」。轉換三行就好：
```js
for(const w in HIT_FX_SPEC){const s=HIT_FX_SPEC[w],k=w==='default'?'_default':w;HITFX[k]=HITFX[k]||{};
 ['bat','bomb','fire'].forEach(h=>HITFX[k][h]=Object.assign({},HITFX[k][h],{hitStopMs:s.hitStopMs[h],shakePx:s.shakePx[h],shakeMs:s.shakeMs}))}
```
`ko` 不是 `hitFx` 的打擊種類，建議在 `bossdown` 事件裡用 `ko` 的值，取代現在的 `shake=4`。
